Cost per Ticket — Model Calculator

Four models of support cost per ticket. Each model has independent parameters. Default values are industry midpoint benchmarks (2024–2025).

Models & parameters

Model 1 Baseline (as-is)
CRM + operator cost
CPT₁ = C N + AHT · OHC
C / N фиксированные затраты на CRM, распределённые на одно обращение; снижаются по мере роста объёма
AHT · OHC прямая стоимость ручной обработки одного обращения оператором

Model 2 RAG copilot
Operator + RAG suggestions
CPT₂ = C N + k · AHT · OHC + ACS
C / N фиксированные затраты на CRM, распределённые на одно обращение
k · AHT · OHC стоимость ручной обработки с учётом снижения AHT: оператор тратит k·AHT часов вместо AHT
ACS стоимость вызова RAG-системы на одно обращение (эмбеддинг + поиск + LLM-инференс)
Cost per ticket — $
Model 3 Auto-response
Auto-response + escalation
CPT₃ = C N + ARC + (1 − AR) · AHT · OHC
C / N фиксированные затраты на CRM, распределённые на одно обращение
ARC стоимость попытки автоответа; применяется ко всему потоку N, независимо от результата
(1−AR)·AHT·OHC взвешенная стоимость ручной обработки: только доля (1−AR) эскалируется к операторам
Cost per ticket — $
Model 4 Auto + RAG
Auto-response + RAG suggestions
CPT₄ = C N + ARC + (1 − AR) · (k · AHT · OHC + ACS)
C / N фиксированные затраты на CRM, распределённые на одно обращение
ARC стоимость попытки автоответа; применяется ко всему потоку N
(1−AR)·(…) стоимость обработки эскалированных обращений с RAG-подсказками и сниженным AHT
